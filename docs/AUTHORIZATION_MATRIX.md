# Authorization matrix

_Generated by `scripts/render_authz_matrix.py` from `src/inkfall/authz.py` and the seed corpus. `Y` = may read; `·` = denied. The same function gates every API path; tests/test_isolation.py checks the API against it._

## Rule

A user may read a document version only if **all** hold (deny wins, unknown labels fail closed):

1. same tenant;
2. version classification <= user clearance (public < internal < confidential < restricted);
3. the user shares at least one ACL group with the version;
4. the user is not on the version's ethical wall;
5. the document is not deleted.

Roles (`admin`, `reviewer`, `counsel`) grant *functions* only: ingest/delete/audit view, approving briefs. They never grant read access. Temporal rules (in force on the as-of date) are applied after authorization.

## Function permissions

| Function | Who | Enforced in |
|---|---|---|
| Read/search/cite/compare/export a version | ACL rule above | `access.authorized_versions`, `access.get_authorized_version` |
| Ingest upload, delete document, quarantine list, records registry | role `admin`, own tenant only | `api.require_role` + tenant from session |
| Audit log view | role `admin` or `reviewer`, own tenant | `api.audit_view` |
| Approve / reject a brief | role `reviewer`, not the author, must be able to read every cited version | `api.decide_summary` |
| Release an approved brief (local outbox) | author or approver; status must be `approved` | `api.release_summary` |
| Review labels | any user, only on versions they can read; reviewers see the tenant's labels | `api.create_review`, `api.list_reviews` |
| Evaluation console | any user; per-question rows limited to own tenant, unreadable refs hidden | `api.eval_report` |
